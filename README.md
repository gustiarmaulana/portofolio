# Gustiar Maulana - IT Analyst Portfolio Website

Website portofolio interaktif yang merangkum kualifikasi, pengalaman, serta proyek perancangan dan pengembangan sistem informasi oleh **Gustiar Maulana, A.Md.S.I.**

🌐 **Live Demo Web Portfolio:** [https://gustiarmaulana.github.io/portfolio/](https://gustiarmaulana.github.io/portfolio/)

## 📌 Deskripsi Singkat
Lulusan D3 Sistem Informasi (UBSI) dengan spesialisasi sebagai **IT Analyst** dan pengolahan data operasional. Terampil dalam menganalisis alur proses bisnis harian, merancang arsitektur sistem (UML, ERD, Flowchart), serta membangun prototipe aplikasi web berbasis Laravel dan MySQL.

---

## 🚀 Proyek Utama (System Prototypes)

1. **Sistem Informasi E-Disposisi Surat Masuk & Keluar**
   * *Fokus:* Digitalisasi alur disposisi pimpinan dan tata kelola pengarsipan surat.
   * *Tech Stack:* Laravel, MySQL, UML Modeling.

2. **Sistem Informasi Kepegawaian Sekolah**
   * *Fokus:* Pengelolaan rekapitulasi data SDM, arsip pegawai, dan administrasi internal.
   * *Tech Stack:* PHP, MySQL, ERD Blueprint.

3. **Sistem Informasi Perpustakaan**
   * *Fokus:* Manajemen sirkulasi peminjaman, pengembalian, dan ketersediaan buku.
   * *Tech Stack:* Laravel, Bootstrap, Use Case Diagram.
